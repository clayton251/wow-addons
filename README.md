# wow-addons

Clayton's World of Warcraft retail addons.

| Addon | Version | Description |
| --- | --- | --- |
| Alt Vault Checklist | 2.1.0 | Account-wide Mythic+ key, Great Vault, weekly, and BiS gear checklists, plus a party key board. Registers each character you log in on. |
| Clayton's Kick & Boss Notes | 1.0.0 | Party and raid interrupt assignments, plus role-aware raid and dungeon boss notes. Display only. |

## Install

Quit the game, then copy each addon folder into:

`World of Warcraft\_retail_\Interface\AddOns`

The folder name must match its `.toc` file (`AltVaultChecklist`, `KickBossNotes`). Enable the addon at character select, or type `/reload` if you are already in game.
